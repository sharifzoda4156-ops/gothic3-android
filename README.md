# Gothic 3 Mobile Remaster — Android

Неофициальный фанатский проект ремастера мобильной игры Gothic 3: The Beginning (Java ME). Проект не связан с правообладателями Gothic и HandyGames; права на оригинальную игру, название и игровые материалы принадлежат соответствующим правообладателям.

Планируется создать Android-приложение на основе [J2ME Loader](https://github.com/nikita36078/J2ME-Loader) с запуском одной игры, сенсорным управлением и подходящими настройками отображения. J2ME Loader распространяется по лицензии Apache 2.0; при использовании его кода необходимо сохранить лицензию и уведомления авторов. Игровые материалы не охватываются лицензией эмулятора.

## Состояние проекта

Проект находится на начальном этапе: исходный код приложения и GitHub Actions ещё не добавлены, APK пока не собран. Запуск, звук, управление и сохранения необходимо проверить на Android-устройстве.

Предыдущий экспериментальный HD-патч не прошёл проверку применимости к актуальным исходникам J2ME Loader. Любые изменения графики нужно отдельно реализовать и проверить.
