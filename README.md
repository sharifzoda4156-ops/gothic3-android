# Gothic 3 Mobile Remaster — Android

Неофициальный фанатский ремастер мобильной игры Gothic 3: The Beginning (Java ME). Проект не связан с правообладателями Gothic и HandyGames; права на оригинальную игру, название и игровые материалы принадлежат соответствующим правообладателям.

Android-оболочка строится на [J2ME Loader](https://github.com/nikita36078/J2ME-Loader), лицензия Apache 2.0. Текст лицензии и сведения об авторах сохраняются в исходном проекте эмулятора. Игровые материалы распространяются отдельно от лицензии эмулятора.

Проект находится в разработке. APK, созданный GitHub Actions, предназначен для тестирования; совместимость, сохранения и управление требуют проверки на устройствах.
